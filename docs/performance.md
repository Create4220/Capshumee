# 性能测试说明

## 版本与条件

**测试版本：卡输咪 1.0.1；日期：2026-11-02。** 本次数据替换 1.0.0 的旧测量值，包含新增的每 100 毫秒 Caps Lock 状态核对。

配置：AMD Ryzen 7 7840H，16 个逻辑处理器，16 GiB 内存，Windows x64，CPU 2 线程。模型是 SenseVoice INT8 ONNX，未使用显卡。

公开中文样本时长 5.592 秒，连续重放三次，共 16.776 秒；每 100 毫秒送入一块 PCM，模拟实时采集节奏。首次加载与后续已加载模型分开测量，再等待自动释放。使用日常程序相同的本地运行库、模型、设置与状态核对代码；不打开麦克风，不读取私人录音，不向输入框或剪贴板输出识别内容。重放入口不安装键盘钩子，但执行定时状态核对，禁用实际录音启动；下方常驻进程快照包含日常键盘监听。

## 已常驻程序的当前进程快照

对日常常驻的 1.0.1 界面与识别进程另作约 19.98 秒外部观察，开始和结束时均未录音。读取进程计数器，不读取录音、输入框、剪贴板或识别正文，也没有控制常驻程序的模型加载状态。

| 进程 | 观察结束时工作集 |
| --- | ---: |

| 本地识别工作进程 | 54.67 MiB |

本段观察期间合计平均 / 峰值工作集均为 86.05 MiB；GetProcessTimes 的 CPU 累计计时未出现可测增量。这是有限时段、有限计时分辨率的结果，不表示程序永远占用 0% CPU。长期运行的内存会因使用历史、缓存及 Windows 工作集调度而变化，不能把快照等同于每台机器的固定占用。

## 如何解释结果

内存使用 GetProcessMemoryInfo，CPU 使用 GetProcessTimes 差值除以墙钟时间与逻辑处理器数；工作集相加可能重复计算共享页，MiB 为 1024 × 1024 字节。峰值 CPU 按约 1 秒窗口计算，不等同于整段平均值。语音阶段最高 1 秒 CPU 为 6.963%，模型释放前仍保留约 378 MiB 工作集。

瞬时峰值、系统后台负载与采样粒度会影响结果。本次结果只描述这台测试设备和短样本，不代表所有录音、电脑或识别准确率，也不包含真实麦克风驱动及目标编辑器的额外开销。

本次测试的 ONNX Runtime 遥测关闭成功；目标进程 IPv4/IPv6 TCP/UDP 端点观察为 0，查询错误为 0。端点轮询不是抓包，不能证明所有极短原生尝试均不存在；程序级防火墙是独立的阻断措施。
