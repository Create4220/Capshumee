# 卡输咪

**轻量级、本地化的 Windows 语音输入工具。** 按 Caps Lock 说话，再按一次停止。无需云端账号，不按使用时长收费，普通 CPU 即可运行。

GitHub 项目名：**Capshumee**。作者：[川宁（Create4220）](https://github.com/Create4220)。

## 下载与安装

### [下载安装包（已含模型与运行环境）](https://github.com/Create4220/Capshumee/releases/latest)

普通使用者请下载 Release 中的 **`Capshumee-1.0.1-Windows-x64-Setup.exe`**，这是卡输咪的安装程序。**不要下载 Source code.zip；无需安装 Python、配置模型或输入命令。**

1. 双击安装包，按中文向导安装。
2. 在附加任务页，选择是否允许“登录 Windows 后自动启动卡输咪”。**默认不勾选，必须由你主动同意。** 也可选择创建桌面快捷方式。
3. 安装末尾会请求一次管理员授权，为本程序添加阻止联网的防火墙规则。这个授权用于离线保护，不是录音授权。
4. 打开桌面或开始菜单的“卡输咪”，将光标放进输入框后按 Caps Lock 使用。

未同意开机自启也能使用，只需每次登录后手动打开。可以随时在托盘右键菜单中开启或关闭自启。**开机启动只进入待机，不会自动录音。**

支持 Windows 10/11 x64。安装包约 **171 MiB**，包含约 228 MiB 的 INT8 模型；安装后约 **319 MiB**，建议为安装临时文件预留 1 GiB。无需独立显卡、CUDA、Docker 或额外 Python 环境。

安装包目前未购买代码签名证书，Windows 可能显示“未知发布者”。请从本仓库 Release 下载，并用同页 SHA256 校验文件核对来源，不要关闭杀毒或防火墙。学校或单位电脑如不允许管理员授权，请管理员协助配置离线保护。

## 怎么用

- **Caps Lock 灯亮**：打开默认麦克风，悬浮窗显示实时预览。
- **说话后停顿**：将确定的短句输入原输入框。
- **Caps Lock 灯灭**：立即关闭麦克风，整理最后一句。
- **右键托盘**：暂停语音输入、复制本轮输出、释放模型、设置自启或退出。

> **为了防止工作时剪贴板冲突，在没有输入框直接输入时，识别结果不会立即同步到剪贴板；请在最小化托盘中右键选择“复制本轮输出”，再手动粘贴。**

窗口切换或写入失败时，本轮文字只暂存在内存里，停止后也不会自动覆盖剪贴板。每次 Caps Lock 开始都是新的一轮，上一轮缓存和延迟返回的结果不会混入；仍属于本程序的旧剪贴板内容会清理，其他软件后来复制的内容不受影响。

Caps Lock 保留原来的大写锁定行为；需要正常输入大写字母时，可先在托盘中暂停。首次说话需要加载模型，之后会更快。SenseVoice 采用短句识别和定期预览，并非逐字原生流式输入。

**1.0.1 修复 Caps Lock 状态偶发反转：** 按键通知只触发检查，录音开关以 Windows 的大写锁定状态为准，每 100 毫秒另行核对；开灯需确认状态稳定并松开按键。程序刚启动、解除暂停或从休眠恢复时，如果灯已亮，请先关灯，再开灯录音。打开麦克风失败后也需重新关灯、开灯，不会持续自动重试。定时核对受 Windows 消息调度影响，不是严格的停止时限。

## 轻量在哪里：实际占用

CPU 推理，默认 2 线程，模型按需加载，空闲约 90 秒自动释放。以下是 **1.0.1 版于 2026-11-02 的重新实测**，包含新增的 Caps Lock 定时核对，**不是所有电脑的性能保证**：

| 状态 | 两进程内存工作集 | 平均 CPU（整机） |
| --- | ---: | ---: |
| 刚启动，尚未加载模型 | 51.8 MiB | 0.013% |
| 首轮公开语音实时重放 | 峰值 378.0 MiB | 1.71% |
| 模型已加载后的语音重放 | 峰值 378.2 MiB | 1.23% |
| 空闲后自动释放模型 | 78.8 MiB | 0.026% |

测试环境：AMD Ryzen 7 7840H、16 个逻辑处理器、16 GiB 内存，Windows x64。CPU 百分比按全部逻辑处理器归一化；内存是界面与识别进程工作集相加，共享页可能重复计入。测试使用官方公开中文样本按实时速率重放，未打开麦克风，也不包含目标编辑器的占用。模型释放前的约 90 秒内仍会保留识别内存。

另外，对已经常驻的 1.0.1 程序独立观察约 20 秒：待机时界面进程约 **31.4 MiB**、识别进程约 **54.7 MiB**，合计 **86.1 MiB**；CPU 累计计时没有出现可测增量，不代表始终零占用。常驻时间、使用历史和采样方式会影响工作集。

首次预览约 **2.83 秒**，已加载模型时约 **1.47 秒**；这些是本次短样本重放结果，实际延迟会受句长、停顿和设备影响。详见 [性能测试说明](docs/performance.md)。

## 本地化与隐私

- 安装包自带模型和运行环境，识别不依赖网络；没有自动下载、更新查询、云转写或遥测。
- 录音和临时文字在本机内存中处理，不保存录音或转写历史，不生成日常运行日志。
- 界面与识别进程通过本机匿名管道通信，专用程序同时受 Windows 入站、出站防火墙阻断。
- 只有主动点击“复制本轮输出”才写入剪贴板，并带 Windows 禁历史记录、禁云同步标记；这些标记不能约束任意第三方剪贴板监控工具。
- 将文字输入或粘贴进其他软件后，由那个软件自行处理；联网文档、聊天应用可能同步输入文字。

## 常见问题

**看不到托盘图标？** 查看任务栏“显示隐藏的图标”，找到像素吉他图标。

**无法录音？** 在 Windows 声音设置中确认默认输入设备，并允许桌面应用访问麦克风。程序只在 Caps Lock 开始时打开麦克风。

**输入框没有文字？** 管理员窗口、密码框或特殊控件可能不接收模拟输入。程序不会自动提权；停止后可右键托盘复制本轮输出。同一浏览器页面中的多个输入框可能共用原生焦点，录音时请避免移动光标或更换输入位置。

**第一次出字慢？** 首次需加载模型。闲置释放模型后，下一轮也会重新加载。

**怎么卸载？** 先从托盘右键退出，再从 Windows“已安装的应用”卸载“卡输咪”。卸载会删除安装文件及本安装的启动项，并请求权限清理本程序的防火墙规则。安装更新前也请先退出托盘。
