# 卡输咪

**轻量级、本地化的 Windows 语音输入工具。** 按 Caps Lock 说话，再按一次停止。无需云端账号，不按使用时长收费，普通 CPU 即可运行。

GitHub 项目名：**Capshumee**。作者：[川宁（Create4220）](https://github.com/Create4220)。

## 下载与安装

### [下载安装包（已含模型与运行环境）](https://github.com/Create4220/Capshumee/releases/latest)

普通使用者请下载 Release 中的 **`Capshumee-1.1.0-Windows-x64-Setup.exe`**，这是卡输咪的安装程序。**不要下载 Source code.zip；无需安装 Python、配置模型或输入命令。**

1. 双击安装包，按中文向导安装。
2. 在附加任务页，选择是否允许“登录 Windows 后自动启动卡输咪”。**默认不勾选，必须由你主动同意。** 也可选择创建桌面快捷方式。
3. 安装末尾会请求一次管理员授权，为本程序添加阻止联网的防火墙规则。这个授权用于离线保护，不是录音授权。
4. 打开桌面或开始菜单的“卡输咪”，按 Caps Lock 开始录音。

未同意开机自启也能使用，只需每次登录后手动打开。可以随时在托盘右键菜单中开启或关闭自启。**开机启动只进入待机，不会自动录音。**

支持 Windows 10/11 x64。安装包约 **171 MiB**，包含约 228 MiB 的 INT8 模型；安装后约 **319 MiB**，建议为安装临时文件预留 1 GiB。无需独立显卡、CUDA、Docker 或额外 Python 环境。

安装包目前未购买代码签名证书，Windows 可能显示“未知发布者”。请从本仓库 Release 下载，并用同页 SHA256 校验文件核对来源，不要关闭杀毒或防火墙。学校或单位电脑如不允许管理员授权，请管理员协助配置离线保护。

## 怎么用

- **Caps Lock 灯亮**：开始录音，悬浮窗显示本轮识别全文。
- **Caps Lock 灯灭**：关闭麦克风，整理最后一句；完成后可直接编辑。
- **悬浮窗**：拖动标题栏移动位置，拖动边框调整大小；长文本自动换行并可滚动。
- **复制**：把编辑后的本轮全文放入剪贴板，关闭本轮窗口；随后按 Ctrl+V 粘贴。
- **取消 / 窗口关闭按钮**：丢弃本轮，关闭悬浮窗；托盘程序继续待机。
- **右键托盘**：显示当前编辑窗口、查看偏好词库、暂停输入、释放模型、设置自启或退出。

**识别结果只进入悬浮窗，停止后也不会自动写入聊天框或剪贴板。点击复制前，可以修改本轮全部文字。** 编辑框中主动使用复制、剪切快捷键时，剪贴板同样带 Windows 禁历史及禁云同步标记；只有窗口下方的整轮“复制”按钮确认会触发学习。

最后一句仍在整理时暂时不能编辑、复制，避免迟到结果覆盖修改。未处理的草稿会一直保留；先复制或取消，再关灯、开灯开始下一轮。复制失败时保留草稿，允许重试。取消后的旧轮结果不会混入下一轮；下一轮只清理仍带本程序私有标记的旧剪贴板，其他软件后来复制的内容不受影响。

Caps Lock 保留大写锁定行为；需要正常输入大写字母时，可先在托盘暂停。启动、解除暂停或休眠恢复时若灯已亮，请先关灯再开灯。状态每 100 毫秒核对，受 Windows 消息调度影响。首次识别需加载模型；SenseVoice 采用短句识别及定期预览。

## 本地自适应调词

在悬浮窗修改识别结果并成功点击“复制”后，程序在本机后台比较原始识别与最终文本，提取短词替换：

- **首次确认**：仅在相同的少量前后文中优先修正；同一上下文的多字词修正确认三次后可用于其他上下文。
- **保守学习**：单字修正始终依赖上下文；数字、纯新增、纯删除和大段重写不直接作为词库规则。整段超过 20,000 字符时跳过学习，仍正常复制全文。
- **可撤销**：托盘“查看 / 管理偏好词库”显示词语、确认次数与状态，可删除选中、清空，或暂停学习与修正。把已自动修正的内容改回原始识别后复制，会停用本轮使用的修正规则。
- **完全本地**：只将短词对应、最多前后各两个字符、确认次数及更新时间保存到本机当前用户的本地应用数据目录。录音和完整原文、修改稿不会写入词库，不会发送给云端。
- **持久化位置**：%LOCALAPPDATA%/Capshumee/preferences.json。更新程序不删除词库；清空词库需用户主动确认。最多保留 1,000 条规则。

这是识别后的文本偏好修正，不改变 SenseVoice 模型权重，也不能保证每次术语判断正确；所有结果仍可在复制前检查和修改。不增加模型、联网服务或第三方依赖。

## 轻量在哪里：实际占用

CPU 推理，默认 2 线程，模型按需加载，空闲约 90 秒自动释放。以下是 **1.0.1 版于 2026-11-02 的重新实测**，包含 Caps Lock 定时核对。以下为历史基线；1.1.0 新增编辑器与词库后的占用尚未重新测量，**不能当作新版性能保证**：

| 状态 | 两进程内存工作集 | 平均 CPU（整机） |
| --- | ---: | ---: |
| 刚启动，尚未加载模型 | 51.8 MiB | 0.013% |
| 首轮公开语音实时重放 | 峰值 378.0 MiB | 1.71% |
| 模型已加载后的语音重放 | 峰值 378.2 MiB | 1.23% |
| 空闲后自动释放模型 | 78.8 MiB | 0.026% |

测试环境：AMD Ryzen 7 7840H、16 个逻辑处理器、16 GiB 内存，Windows x64。CPU 百分比按全部逻辑处理器归一化；内存是界面与识别进程工作集相加，共享页可能重复计入。测试使用官方公开中文样本按实时速率重放，未打开麦克风，也不包含目标编辑器的占用。模型释放前的约 90 秒内仍会保留识别内存。

另外，对已经常驻的 1.0.1 程序独立观察约 20 秒：待机时界面进程约 **31.4 MiB**、识别进程约 **54.7 MiB**，合计 **86.1 MiB**；CPU 累计计时没有出现可测增量，不代表始终零占用。常驻时间、使用历史和采样方式会影响工作集。

首次预览约 **2.83 秒**，已加载模型时约 **1.47 秒**；这些是本次短样本重放结果，实际延迟会受句长、停顿和设备影响。详见 [性能测试说明](docs/performance.md)。

## 本地化与隐私

- 安装包自带模型和运行环境，识别不依赖网络；没有自动下载、更新查询、云转写或遥测。
- 录音和完整草稿在本机内存中处理，不保存录音或转写历史，不生成日常运行日志；确认过的短词修正可保存为本地偏好词库。
- 界面与识别进程通过本机匿名管道通信，专用程序同时受 Windows 入站、出站防火墙阻断。
- 只有用户主动复制或剪切才写入剪贴板，并带 Windows 禁历史记录、禁云同步标记；这些标记不能约束任意第三方剪贴板监控工具。
- 将文字输入或粘贴进其他软件后，由那个软件自行处理；联网文档、聊天应用可能同步输入文字。

## 常见问题

**看不到托盘图标？** 查看任务栏“显示隐藏的图标”，找到像素吉他图标。

**无法录音？** 在 Windows 声音设置中确认默认输入设备，并允许桌面应用访问麦克风。程序只在 Caps Lock 开始时打开麦克风。

**聊天框为什么没有自动出现文字？** 1.1.0 采用悬浮窗确认流程：停止后编辑、点击复制，再自行粘贴。

**调词不合适怎么办？** 在托盘打开偏好词库，删除对应项或暂停调词。取消一轮不会学习本轮修改。纯删除不等于不喜欢某个词，不会自动记成永久删除规则。

**第一次出字慢？** 首次需加载模型。闲置释放模型后，下一轮也会重新加载。

**怎么卸载？** 先从托盘右键退出，再从 Windows“已安装的应用”卸载“卡输咪”。卸载会删除安装文件及本安装的启动项，并请求权限清理本程序的防火墙规则。安装更新前也请先退出托盘。
